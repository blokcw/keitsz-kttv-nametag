    功能總覽及說明

    由準備講稿到剪片加字幕，每個階段用邊個工具、點樣用，喺呢度一次睇晒。

    1. 前期準備講稿提詞機
    2. 拍攝現場拍攝電子場記板拍攝中告示
    3. 後期剪片包裝人名字幕條標題角標調色室檔案轉換

    前期

    提詞機 Teleprompter

    主播讀稿用。貼上講稿，大字慢慢捲動，眼睛望住鏡頭都讀到。

    • 自動計算字數同預計讀稿時間（中文每分鐘約 240 字）
    • 左右鏡像、上下翻轉，配合提詞機玻璃
    • 捲動速度可隨時調；「自動配速」按預計時間設定
    • 黃字黑底 / 白字黑底，字體大小可調
    • 全螢幕、螢幕唔會自動熄；Mac 鍵盤同翻頁遙控器都用得
    開啟提詞機

    拍攝

    電子場記板 Slate

    每次開機錄影前打板，方便剪片時搵返邊條片，同埋對齊影像同聲音。

    • 大字顯示 Scene、Take、Roll、機位、日期同時間碼
    • 一按 CLAP：白閃畫面 + 1kHz 嗶聲做同步點
    • Take 自動加 1；「下一場」自動轉場
    • 拍板記錄可以下載 CSV
    開啟場記板

    拍攝

    拍攝中告示 On-set Sign

    放喺課室門口嘅亮燈告示，提醒其他人保持安靜、唔好入嚟。

    • 五款預設：拍攝中、錄音中、請勿進入、綵排中、休息中
    • 文字可以自行修改
    • 全螢幕顯示，顯示已開始時間，螢幕唔會自動熄
    開啟告示

    後期

    人名字幕條 Name Tag

    受訪者、主播出鏡時，喺畫面下方出現嘅動畫名字條。

    • 名字、身份、標籤自由輸入；常用身份一按填寫
    • 七款主題（校色、畢業、運動會、聖誕、復活節等），配套動畫圖案
    • 校徽或者自己上載嘅圖示
    • 錄成綠幕影片（MP4），或者透明 PNG
    開啟人名字幕條

    後期

    標題角標 Titles & Lower Thirds

    節目片頭大標題、畫面四角嘅 Logo 同節目名、下方標題字幕，一次過設計好。

    • 文字同 Logo 可以放喺四角或者九宮格任何位置，亦可以自由拖放
    • 調整字體、大小、顏色、字距、外框、陰影、底色
    • 四個範本：角標組合、節目大標題、下方標題、直播角標
    • 支援 16:9、9:16、4:3、1:1、4:5 等畫面比例，一鍵轉直向 / 橫向
    • 匯出透明 PNG（標準或 2 倍解像度）
    開啟標題角標

    後期

    調色室 Color Grading

    拍完覺得太暗、太黃、冇感覺？上載相片或者影片，即時調色，分割畫面比較前後。

    • 曝光、亮度、對比、高光、陰影、色溫、色調、飽和度、自然飽和度、褪色
    • 九款內置風格（電影感、日系清新、復古菲林、黑白等）或者上載 .cube LUT，可調強度
    • 參考配色：上載參考相片 / 影片並排比較，一鍵套用參考色調，換素材自動重新配對
    • 分割 / 並排 / 按住睇原圖；直方圖提示過曝同黑位
    • 原解像度下載相片；影片保留聲音；可以下載 .cube 帶去其他剪片軟件
    開啟調色室

    常見問題

    點樣放喺 iPad 主畫面，好似 App 咁開？

    用 Safari 開呢個網頁，撳「分享」→「加入主畫面」。之後喺主畫面撳圖示就會全螢幕打開。

    我嘅講稿、設定同上載嘅圖示儲存喺邊？

    全部只會儲存喺你用緊嗰部機嘅瀏覽器入面，唔會上載。換機或者用「私密瀏覽」就唔會見到。清除 Safari 網站資料亦會刪除。

    點樣知道有冇新版本？

    每次打開網頁都會自動檢查。有新版本，畫面底部會出現「有新版本 · 撳此更新」。更新之後會彈出「最新功能」介紹。頁尾會顯示目前版本。

    場記板聽唔到嗶聲？

    iPhone 要關閉側邊靜音掣，同埋調高音量。iPad 檢查控制中心音量。可以喺場記板設定撳「試聽嗶聲」測試。

    匯出嘅影片 iMovie 讀唔到？

    請用 Safari 或者新版 Chrome 錄製，咁就會係 MP4。Firefox 只會出 WebM 格式。

    透明 PNG 點樣放入影片？

    將 PNG 拖入剪片軟件，放喺影片上面一層，再拉長到需要嘅時間。iMovie 揀「畫中畫」或者「疊加」，CapCut 揀「疊加」。

    檔案轉換會唔會將我嘅檔案上載？

    唔會。所有轉換都喺你部機嘅瀏覽器入面做。第一次轉影片或者音訊時，會由網上下載一次約 30 MB 嘅轉換引擎，之後會快好多。

    點解影片轉換咁慢？

    工具會優先用部機嘅硬件編碼（新版 Safari / Chrome，MP4 / MOV / MKV / WebM）。如果揀咗 AVI、FLV、WMV，或者要替換音軌、封裝字幕，就要用軟件引擎，速度會慢好多；H.265、AV1 軟件編碼尤其慢。長片建議用 Mac。

    建議用咩裝置？

    iPad（打橫）最適合提詞機、場記板同告示；Mac 或者 iPad 都可以做字幕同標題。長時間使用建議插住電。
